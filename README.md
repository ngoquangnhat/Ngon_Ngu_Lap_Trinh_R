# Git Foundation Practice - AKA Lab

## Giới thiệu

Repository này được tạo nhằm thực hành các kiến thức nền tảng về Git và GitHub trước khi tham gia khóa học Vibe Coding tại AKA Lab.

## Mục tiêu học tập

* Hiểu vai trò của Git trong quản lý phiên bản phần mềm.
* Thực hành tạo và quản lý Git repository.
* Làm quen với GitHub Flow.
* Thực hành làm việc với branch và pull request.
* Thực hành xử lý merge conflict.
* Thực hành rollback/revert khi có thay đổi gây lỗi.

## Danh sách lệnh Git đã sử dụng

* `git clone`
* `git add`
* `git commit`
* `git push`
* `git pull`
* `git branch`
* `git switch`
* `git merge`
* `git revert`
* `git status`
* `git log`

## Các branch đã thực hành

1. `feature-readme`
2. `feature-git-command`
3. `feature-conflict`

## Pull Request đã thực hiện

* Pull Request 1: Cập nhật README và mục tiêu học tập.
* Pull Request 2: Bổ sung các lệnh Git nâng cao.

## Thực hành Conflict

Đã tạo tình huống merge conflict bằng cách chỉnh sửa cùng một file ở nhiều branch khác nhau và thực hiện resolve conflict thành công.

## Thực hành Rollback/Revert

Đã tạo một thay đổi giả lập gây lỗi và sử dụng `git revert` để hoàn tác thay đổi đó.

## Tôi sẽ dùng Git như thế nào khi Vibe Code với AI?

Tôi sẽ sử dụng Git như một công cụ quản lý phiên bản và đảm bảo an toàn khi lập trình cùng AI. Trước khi để AI sinh code hoặc chỉnh sửa hệ thống, tôi sẽ tạo branch riêng để thử nghiệm, commit theo từng bước nhỏ để dễ kiểm soát thay đổi, sử dụng pull request để kiểm tra nội dung cập nhật và rollback/revert khi code do AI sinh ra gây lỗi hoặc làm mất ổn định hệ thống.
